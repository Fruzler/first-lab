# Відповіді на питання для самоконтролю

1. **Чому важливо вказувати user.name та user.email?**
   Вони ідентифікують автора кожного коміту. Це дозволяє команді знати, хто саме вніс зміни в код, а також пов'язує коміти з профілем на GitHub.

2. **Яка різниця між git pull і git fetch?**
   `git fetch` завантажує нові зміни з віддаленого репозиторію, але не об'єднує їх з вашим кодом. `git pull` виконує `git fetch`, а потім одразу автоматично об'єднує (`git merge`) зміни у вашу поточну гілку.

3. **Як скасувати останній коміт, не втрачаючи зміни у файлах?**
   Використовується команда `git reset --soft HEAD~1`. Вона скасовує сам коміт, але залишає всі ваші зміни у файлах і в індексі (staged).
